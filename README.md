## What I'm Building

### 1. TariffIQ — AI Customs Classification Copilot

An AI-assisted customs classification and HTS retrieval system built around official USITC HTS data ingestion, attribute extraction, and Hybrid Top-K retrieval. It uses structured LLM reasoning within a candidate-constrained classification flow, with a hard validation boundary and explicit confidence, evidence, and clarification outputs.

- HTS code search, Chapter 99 ingestion, and offline fallback
- `Python` · `TypeScript` · `OpenAI Structured Outputs` · `Retrieval` · `Data Pipelines`

### 2. [TraceLens AI — Production Incident Investigation](https://github.com/xxy614/tracelens-ai)

A production incident investigation system that parses structured and unstructured logs, normalizes events, and correlates request IDs and trace IDs. Deterministic root-cause analysis works without an API key, while optional LLM enhancement adds context to incident timelines, evidence, confidence, and remediation suggestions.

- `FastAPI` · `React` · `TypeScript` · `PostgreSQL` · `SQLAlchemy` · `Docker` · `GitHub Actions`
- [View repository →](https://github.com/xxy614/tracelens-ai)

### 3. TaskForge — Distributed Job Queue & Worker Orchestration

A distributed job-processing system for asynchronous work and worker orchestration. It covers retries with exponential backoff, dead-letter queues, idempotency, distributed locks, priority scheduling, rate limiting, worker heartbeats, observability, and failure recovery.

- `Python` · `FastAPI` · `PostgreSQL` · `Redis` · `Docker` · `Prometheus` · `CI`

### 4. FanPulse — Data Engineering & Analytics Pipeline

A synthetic ticketing and fan-intelligence data project that moves raw transactions through transformation, validation gates, and atomic publishing into curated analytical datasets. It supports event, sales-channel, and fan-segment analysis, including natural-language analysis grounded in trusted data.

> All data is synthetic. This project is not affiliated with the Los Angeles Chargers.

- `Python` · `SQL` · `Data Modeling` · `Data Quality` · `Analytics Engineering`

### 5. [RoboPercept — Robotics & Perception](https://github.com/xxy614/RoboPercept)

Robotics-oriented computer vision and perception work spanning multi-source sensor data, real-time inference, and hardware-software integration. The project focuses on building reproducible perception pipelines for software that operates in physical environments.

- `Python` · `PyTorch` · `OpenCV` · `Computer Vision` · `Robotics`
- [View repository →](https://github.com/xxy614/RoboPercept)
